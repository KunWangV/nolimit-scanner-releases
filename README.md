# NoLimit Scanner

Official signed Android APKs for NoLimit Scanner (拍文档 / 拍文件).

Download the APK and SHA256SUMS.txt from [Releases](https://github.com/KunWangV/nolimit-scanner-releases/releases). To verify the download, run `shasum -a 256 -c SHA256SUMS.txt` from the directory containing both files.
